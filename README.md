# mayavi-data

Mirror of the datasets the [Mayavi](https://github.com/enthought/mayavi) examples download, so the examples and the docs gallery do not depend on a single upstream host.

The files are attached to the [`stanford-v1` release](https://github.com/larsoner/mayavi-data/releases/tag/stanford-v1), byte for byte as originally published:

| File | Example(s) | Original URL | SHA-256 |
| --- | --- | --- | --- |

| `dragon.tar.gz` | `mlab/dragon.py` | http://graphics.stanford.edu/pub/3Dscanrep/dragon/dragon_recon.tar.gz | `74ac1d90989c9b1732edee82d57e9ce71452144cf4355f108d8c9c616d28d02f` |
| `lucy.tar.gz` | `mlab/lucy.py` | http://graphics.stanford.edu/data/3Dscanrep/lucy.tar.gz | `c4beb1f7bfa965643bbbf889bd1849a4b4b955e95c731941be61e6edac65616a` |
| `MRbrain.tar.gz` | `mlab/mri.py`, `advanced_visualization/tvtk_segmentation.py` | http://graphics.stanford.edu/data/voldata/MRbrain.tar.gz | `934a4631f1c168b8bfe9e9597a20e472cc6c188ade56e99de428a2b0f20ed58c` |

## Source and terms

All four come from Stanford University: the meshes from the [Stanford 3D Scanning Repository](http://graphics.stanford.edu/data/3Dscanrep/), the MRI volume from the [Stanford volume data archive](http://graphics.stanford.edu/data/voldata/).
Stanford's terms of use, as given on those pages, apply unchanged to these copies; in particular, acknowledge the Stanford Computer Graphics Laboratory when using them.
